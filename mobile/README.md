# Nocta · Mobil uygulama

Expo SDK 57 + expo-router. Kurulum ve test adımları için depo kökündeki `README.md` dosyasına bakın.

```bash
npm install
npx expo start --tunnel
```

- Ekranlar: `src/app/` (dosya tabanlı yönlendirme)
- Oyun motorları: `src/components/games/`
- Tasarım sistemi: `src/theme/`, `src/components/ui.tsx`
- Supabase istemcisi ve tipler: `src/lib/`
- Oturum/çift/içerik durumu: `src/providers/`
